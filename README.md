
# AI-Based Intelligent Language Detection System Using OpenCV

## Project Overview
An AI-powered language detection system designed to support real-time communication using computer vision and machine learning techniques.

## Features
- Real-time camera input using OpenCV.
- AI-based language recognition.
- Text processing and prediction.
- Multilingual communication support.
- Interactive user interface.
- Real-time results.

## Technologies Used
- Python
- OpenCV
- Machine Learning
- NLP
- Scikit-learn
- Streamlit

## Installation

1. Clone the repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:
   ```bash
   cd AI-Language-Detection
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:
   ```bash
   streamlit run app.py
   ```

## Project Structure
- `app.py` – Main application.
- `language_model.pkl` – Trained ML model.
- `tfidf_vectorizer.pkl` – Text vectorizer.
- `requirements.txt` – Project dependencies.
